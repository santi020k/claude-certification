# Security policy

Security updates are provided for the current `main` branch. This is a learning
project, not a hosted service or supported SDK.

Please report vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/santi020k/claude-certification/security/advisories/new).
Do not include API keys, access tokens, or private conversation content in an
issue, pull request, or reproduction repository.

Include the affected component, reproduction steps, impact, and any suggested
mitigation. Reports will be acknowledged as soon as practical.
